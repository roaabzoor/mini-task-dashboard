# Mini Task Management Dashboard

A simple Task Management Dashboard built using Next.js and TypeScript.

The application allows users to view tasks, search and filter tasks, open task details, and add new task.

## Features

- Dashboard overview
- Task list
- Search tasks
- Filter tasks by status
- Dynamic task details page
- Add Task form
- Server Actions
- Loading state
- Error state
- Metadata
- Responsive interface

## Technologies Used

- Next.js
- TypeScript
- React
- Tailwind CSS
